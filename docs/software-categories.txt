## Mail: running a mail server
Stalwart is the all-in-one choice (SMTP, IMAP, JMAP, calendars, contacts). The classic route is Postfix (sends and receives) with Dovecot (mailboxes, IMAP), Rspamd (spam) and a webmail.
- stalwart | SMTP, IMAP, POP3, JMAP, CalDAV and CardDAV in one program (the first choice)
- postfix | the classic SMTP server
- dovecot | IMAP/POP3 mailboxes (with Pigeonhole for Sieve filters)
- rspamd | spam filtering and DKIM signing
- opensmtpd | a small alternative SMTP server
- exim | another SMTP server, very configurable
- mox | a complete mail server in one Go program
- clamav | virus scanning for mail and files
- listmonk | newsletters and mailing lists

## Mail: webmail and groupware
- roundcube | the standard webmail
- snappymail | a fast, light webmail (fork of RainLoop)
- sogo | webmail, calendars and contacts for Outlook-style groupware
- radicale | small CalDAV/CardDAV server (calendars and contacts)
