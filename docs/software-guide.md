# Software guide

What the main software in the tree is for, by area: a reminder when planning a home lab or a
small-business server. The areas and the names are in `docs/software-categories.txt`; the
version and the one-line description of each package are read from its recipe. Generated by
`tools/gen-software-docs.sh`: do not edit by hand. Every package in the tree is listed in
[software-index.md](software-index.md).

Server packages are **inert**: installing one enables no service, opens no port and sets up
no site or cron job (the package's `README.FenrirOS`, where there is one, says how to set
it up; some apps create their own first-run login, which the README names). Services start
with dinit: `dinitctl start NAME`; to run one at every boot, link it into
`/etc/dinit.d/boot.d`. A recipe in the tree is not necessarily built yet: see
[roadmap.md](roadmap.md) for the state of things.
